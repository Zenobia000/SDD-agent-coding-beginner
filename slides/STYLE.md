# 視覺規範｜冷綠莫蘭迪 × 黏土鱷

## 色票（與上一代暖玫瑰貓對撞）

| 角色 | HEX | 用途 |
|---|---|---|
| 冷灰綠紙 | `#E4E7E3` | 頁面底 |
| 鱷霧綠 | `#6B7F6A` | 主強調、吉祥物身 |
| 冷青灰 | `#5F7A7A` | 次強調、領巾 |
| 沙陶 | `#C4B8A8` | 肚／溫暖點綴 |
| 炭褐字 | `#3A3735` | 標題與內文 |

禁止：高飽和綠、霧玫瑰主色、品牌 logo、紫霓虹、整頁表格。

## 字與形

- 標題當圖、可大可鬆；說明字小而安靜
- 軟邊紙片、步道、軌道、管線——圖像記憶優先
- 黏土鱷每頁出場一次，不搶內容
