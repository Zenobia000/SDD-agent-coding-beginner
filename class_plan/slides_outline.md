## [S10] 找痛點的魔法 prompt

```
（複製貼上到 ChatGPT / Claude）

你是一位痛點結構化教練。我腦中有一些模糊的工作 / 生活痛點。

請用蘇格拉底式提問（一次一題）引導我整理出 3 個具體痛點，
每個痛點包含：
- 誰遇到（具體的人）
- 情境（什麼時候）
- 現行解法（現在怎麼處理）
- 不滿（哪裡煩）

規則：一次一題，我回答後再問下一題；
我回答太抽象時請直接指出；
不要評分或建議產品。

開始問我第一題吧。
```

**Speaker Notes：** 把 prompt 貼到共用文件，讓學員複製。

## [S18] STRIKE 六字訣（核心投影片）

```
Prompt 工程的核心框架

S  Situation  情境    交代背景，讓 AI 不用猜
T  Task       任務    明確說做什麼、產出什麼
R  Role       角色    指定 AI 扮演的專業身分
I  Input      輸入    餵資料，不讓 AI 瞎猜
K  KPI        驗收    定義什麼叫「夠好」
E  Example    範例    給樣本，鎖定輸出方向

口訣：情境定場 → 任務定向 → 角色定級
     → 輸入定料 → 標準定規 → 範例定調
```

**視覺：** 六格方塊、每格大字母 + icon、不同底色
**Speaker Notes：** 這是今天的旗艦投影片，學員的 STRIKE 速查卡也長這樣。

## [S19] 每格怎麼寫好（一）：S / T / R

```
S 情境定場
  ❌ 空泛："我想要..."
  ✅ 具體："我是消費品行銷經理，準備 Q2 檢討會議"

T 任務定向（動詞 + 產出物，一個 prompt 一件事）
  ❌ "整理一下"
  ✅ "整理成三段摘要，含待辦清單和負責人"

R 角色定級（決定 AI 的專業天花板）
  ❌ "你是助理"
  ✅ "你是資深社群媒體分析師"
```

---

## [S20] 每格怎麼寫好（二）：I / K / E

```
I 輸入定料（AI 沒資料就瞎猜）
  ✅ "以下是我方 Q2 貼文數據：[貼上數據]"

K 標準定規（定義什麼叫「夠好」）
  ✅ 格式：表格 / 字數：800 內 / 語氣：中立 / 禁止：推測

E 範例定調（一個範例省三輪來回）
  ✅ "參考這份過去的成功範本：[貼上]"

━━━━━━━━━━━━━━━━━━━━━━
沒有 E 也沒關係。
沒有 T+K+I？那 AI 一定瞎掰。
```

## [S21] 趕時間救命組合：T + K + I

```
MVP 最小可用組合

   T       K        I
 任務  +  驗收  +  輸入
  ↓       ↓        ↓
動詞+產出  格式+字數  貼資料

三格填好 → 品質從「碰運氣」跳到「八成可用」

STRIKE 全寫 = 100% 滿分
T+K+I 填滿 = 80% 可用
連 T+K+I 都沒 = 10% 運氣
```

**視覺：** 三個輪子、並排、亮色強調
**Speaker Notes：** 這是給初學者的救命稻草。記不住六格沒關係，先會三格就行。

## [S30] Vibe Coding 五步流程

```
1. 描述需求     ← 用 M2 的 STRIKE（PRD 就是 L2 精準打擊）

2. 看 AI 規劃    ← AI 列出：做什麼檔案、用什麼技術
                 → 你確認方向對

3. 看程式碼     ← 不用懂，但要看
                 → 不懂的地方直接問 AI：這段在做什麼？

4. 測試         ← 跑起來、點一點、貼資料試

5. 自然語言修正  ← 「太擠」「加匯出」「顏色改深藍」

→ 回到 3、4 直到滿意
```

## [S45] @ 引用：把檔案丟進對話

```
舊招（M4 前半教過）：
  cat news.txt | agy "摘要"

新招（更簡單）：
  agy "@news.txt 幫我摘要"

差別：
  cat |   = 把檔案內容「灌」進去（適合單檔、純文字）
  @file   = 告訴 agent「自己去讀」（適合多檔、大檔、含程式碼）

多檔範例：
  agy "@README.md @src/main.py 解釋這個程式怎麼跑"
```

**視覺：** 左右兩欄對比，cat | 用箭頭灌入、@ 用箭頭指向檔案（agent 主動讀）。
**Speaker Notes：** @ 是業界共識——Cursor、Claude Code、Antigravity 都用同樣語法。先用 cat 練手感、再升級到 @，學員會自己「啊這個更方便」。

## [S46] 內建工具 + 三層保險

```
Antigravity CLI 不只會聊天，它預設帶這些工具：

  📂 ReadFile / WriteFile    讀寫檔案
  🐚 Shell                   跑指令
  🔍 GoogleSearch            即時上網查
  🌐 WebFetch                讀網頁

三層保險（事前 → 事中 → 事後）：

  事前    首次啟動：逐資料夾信任授權       只信你自己的工作區
  事中    每次動手：先問你「可以嗎？」     動檔 / 跑指令前停下
  事後    改錯了：打 /restore 選快照回滾   比 git reset 安全（不動 git 歷史）

🟡 三層遞進保你：信錯資料夾 / 答錯確認 / AI 改壞了，
   都還有救命繩。
```

**視覺：** 上半顯示四個工具 icon + 名稱；下半「事前 / 事中 / 事後」三欄式排列，每欄用淡色卡片，事後那欄底色加強（救命繩最重要）。
**Speaker Notes：** **「事後」這層是學員最常踩雷的救命繩**——AI 改錯 5 個檔案、你想哭，打 `/restore` 選快照就回到改之前。比 git reset 安全，不動 git 歷史。當場 demo：改一個檔 → 故意叫 AI 改錯 → 打 `/restore` → 看 CLI 列出快照清單 → 選編號 → 檔案瞬間回滾。沒開過 checkpointing 的話這時要哭。所以本模板 `.agents/settings.json` 預設 `checkpointing.enabled: true`。
