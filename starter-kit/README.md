# 企業啟動包

> 給要在公司推動 AI 的決策者與主管。主題：**AI 的回報卡在組織，不在模型。**
> 原稿在這個資料夾；成品用 `python3 scripts/build-html.py` 產生 `dist/starter-kit.html`（報告）與 `dist/deck.html`（高層簡報）。

| 位置 | 是什麼 | 狀態 |
|---|---|---|
| [`report/`](./report/00-summary.md) | 主報告：執行摘要與十章 | 執行摘要、第 1–3 章初稿 |
| `functions/` | 十個部門與系統的拆解 | 未開始 |
| `tools/` | 五個工具：場景挑選、成熟度自評、使用政策範本、效益衡量表、數位員工上崗檢核表 | 未開始 |
| `deck/` | 20 頁高層簡報 | 未開始 |
| [`storyline.md`](./storyline.md) | 空白簡報：全部行動標題與圖表清單 | 已定稿 |
| [`STYLE.md`](./STYLE.md) | 寫作與圖表規範 | 已定稿 |
| [`research/`](./research/01-gap.md) | 六份研究，所有數字的出處 | 有待補查清單 |

寫作前先讀 `STYLE.md`；改完跑 `python3 scripts/build-html.py --outline`，只讀標題要能讀懂整份報告。
