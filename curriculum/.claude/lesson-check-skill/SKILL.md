# /lesson-check — 教材規約核對器

> **唯讀**。本 skill 只回報，不改檔。要改請使用者確認後另外動手。

## 檢查對象

`$ARGUMENTS` 指定的檔案或目錄。留空時預設檢查 `curriculum/` 下所有 `.md`。

## 執行步驟

### Step 1：確定檔案類型，套對應規則

| 路徑樣式 | 適用規則 |
|---|---|
| `curriculum/S<n>-*.md` | 全套（七段骨架 + 八條紀律） |
| `curriculum/instructor/*.md`、`curriculum/cards/*.md` | 只查八條紀律，不查七段骨架 |
| `docs/concepts/**` | 只查「結論卡」與「證據分級」（規約 §4 例外） |
| `labs/reference-project/**/expected/**` | **跳過**（產出物快照，不受規約約束） |
| `docs/legacy/**` | **跳過**（退役存檔，只讀） |

### Step 2：逐項核對（二元判準，不給分數）

**A. 七段骨架**（僅站別教材）
順序必須是：結論卡 → 課堂 15 分鐘版 → 動手 → 閘門 → 我做對了嗎 → 回家展開版 → 下一步。
- [ ] 七段都在？
- [ ] 順序正確？
- [ ] 段名逐字相符（不可改寫）？

**B. 八條紀律**
- [ ] 第一個非標題段落就是結論？（不可用「在開始之前」類開場）
- [ ] 需要讀者做的決定 ≤ 1 個？
- [ ] 每個清單 ≤ 5 項？
- [ ] 事實宣稱都有「已確認 / 推測 / 未知」標記？
- [ ] 時間估計有給區間與前提？
- [ ] 專有名詞第一次出現有白話解釋，且只解釋一次？
- [ ] 沒有重述其他文件的內容（該用連結的地方用了連結）？
- [ ] 結尾恰好一個下一步？

**C. 硬限制**
- [ ] 「結論卡」≤ 5 行？
- [ ] 「閘門」≤ 5 條且全部是 yes/no？
- [ ] 「動手」每步恰好一個動作？
- [ ] 「我做對了嗎」有指向 `labs/reference-project/` 的具體檔名？

**D. 連結有效性**
用 Grep 撈出所有 `](./` 與 `](../` 相對路徑，逐一確認目標存在。

### Step 3：輸出

嚴格照這個格式，不要加別的：

```
<檔案路徑>

判定：通過 / 未通過

未通過的項目（通過就寫「無」）：
1. <哪一條> — <證據：第幾行 / 引用原文>
   修正：<一句話，具體到可以直接動手>

下一步：<恰好一個動作>
```

多個檔案時，**先列未通過的**，通過的最後用一行帶過（`✅ 通過：a.md, b.md, c.md`）。

## 不要做的事

- ❌ 不要自動修改檔案（本 skill `disallowed-tools` 已擋掉 Write/Edit）
- ❌ 不要給 1–10 分。規約是二元判準（`docs/concepts/binary-rubric.md`）
- ❌ 不要因為「內容寫得很好」就放寬格式檢查——格式是為了讀者的認知負荷，不是為了作者
- ❌ 不要一次列超過 5 個問題。超過就只列最嚴重的 5 個，並註明「另有 N 項，修完這 5 個再跑一次」

## 常見誤判

| 看起來違規 | 其實合規 |
|---|---|
| 「回家展開版」裡有 12 項清單 | 規約 §4 例外：該段長度不限、可多分支 |
| `docs/concepts/` 沒有七段骨架 | 規約 §4 例外：參考讀本不需要 |
| 同一術語在不同檔案各解釋一次 | 合規。「只解釋一次」是同一份文件內 |
