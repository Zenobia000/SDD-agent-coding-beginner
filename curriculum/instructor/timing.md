## S0 開機（09:00–09:30，30 分）

| 分 | 誰 | 做什麼 |
|---|---|---|
| 0–5 | 講師 | 開場三句：不教講話、只有四拍、每站打 `/gate` |
| 5–10 | 講師 | 示範一次 `/gate` 長什麼樣（用參照專案跑給大家看） |
| 10–25 | 學員 | 跑 S0 動手五步 |
| 25–30 | 全體 | 打 `/gate`，確認全班過關 |

**講師必做**：第 10 分鐘把沒有訂閱的人集中到一區，助教一對一處理免費路線。
**這是全天最容易塞車的點。**

**超時處理**：25 分還有人卡在安裝 → 讓他用**參照專案**跟著跑（`labs/reference-project/`），
環境午休再修。**不要讓一個人卡住全班。**

---

## S1 問對問題（09:30–10:25，55 分）

| 分 | 誰 | 做什麼 |
|---|---|---|
| 0–5 | 講師 | 三個要點（問對問題比 prompt 貴、寫得出 check() 嗎、不做什麼是主防線） |
| 5–10 | 講師 | 示範 `/frame` 的前兩題，用自己的例子 |
| 10–45 | 學員 | 跑 `/frame` 五題 + 產決策卡 |
| 45–50 | 全體 | 三個人分享「不做什麼」欄位（**只分享這一欄**） |
| 50–55 | 全體 | 打 `/gate` |

**講師巡場只盯一件事**：第 3 題（怎麼判斷做對了）有沒有被含糊帶過。
聽到「品質好」「順一點」「比較準」→ 過去追問。

**追問話術**：
> 如果有兩個版本擺在你面前，你會看什麼、數什麼、比什麼？

---

## S2 定契約（10:35–11:30，55 分）

| 分 | 誰 | 做什麼 |
|---|---|---|
| 0–5 | 講師 | Business Rule vs Model Rule，現場刪一份 spec 給大家看 |
| 5–30 | 學員 | 跑 `/spec` |
| 30–50 | 學員 | 跑 `/evals` + 記錄基線 |
| 50–55 | 全體 | 打 `/gate` |

**講師巡場只盯一件事**：考卷有沒有邊界 case。
只有主流程的考卷 → 過去說「把空輸入那題加上」。

**這一站超時的話，寧可砍 S3 也不要砍這裡。** 沒有考卷，下午整個 S4 會失去意義。

---

## S3 先跑通（11:30–12:10，40 分）

| 分 | 誰 | 做什麼 |
|---|---|---|
| 0–5 | 講師 | 為什麼排在 S2 之後、為什麼 v0 要丟掉 |
| 5–30 | 學員 | 貼 spec 到平台、拿到 v0 |
| 30–37 | 學員 | 用考卷手動抽測 3 筆 |
| 37–40 | 全體 | 打 `/gate` |

**講師此時要說的一句話**：
> 等一下吃飯的時候想一件事——你的 v0 在哪裡爆掉了？那就是下午要解的問題。

**平台掛掉 / 沒網路** → 見 [`fallback.md`](./fallback.md)。

---

## S4 迴圈開工（13:00–14:30，90 分）

| 分 | 誰 | 做什麼 |
|---|---|---|
| 0–5 | 講師 | v0 丟掉、TDD 三步、寫完不是結束 |
| 5–15 | 學員 | `內建 plan 模式` 拆任務 |
| 15–65 | 學員 | `/tdd` 實作 |
| 65–70 | **講師** | **喊停**：「還在寫 code 的人，停下來跑 `/review`」 |
| 70–85 | 學員 | 跑考卷 + `/next` |
| 85–90 | 全體 | 打 `/gate` |

**第 65 分鐘的喊停是本站最重要的講師動作。**
最常見的失控是學員一路寫到收工都沒驗證過。

**巡場重點**：
- 有人的 Now 有 5 個以上 task → 叫他砍到 3 個
- 有人跳過 RED 直接寫實作 → 讓他刪掉重來一次（這個痛要親身經歷）
- 有人 `/next` 只跑了一輪 → 提醒「一輪不叫曲線」

---

## S5 方法變資產（14:40–15:35，55 分）

| 分 | 誰 | 做什麼 |
|---|---|---|
| 0–5 | 講師 | 六種資產的決策表，**重點講「能被違反嗎」那一欄** |
| 5–10 | 講師 | 現場改一個 hook 並實測給大家看 |
| 10–30 | 學員 | 改 hook + 實測 |
| 30–50 | 學員 | 寫 command |
| 50–55 | 全體 | 打 `/gate` |

**講師必須確認每個人都親眼看到自己的 hook 擋下東西。**
沒有這個體感，「機械層」對他們只是一個詞。

**這一站不要砍。** 這是全天唯一教「寫」的一站。

---

## S6 積木裝配（15:35–16:20，45 分）

| 分 | 誰 | 做什麼 |
|---|---|---|
| 0–5 | 講師 | 全端是「看得出缺哪塊」；接點比單塊難 |
| 5–10 | 學員 | `/next` 看建議、挑兩塊 |
| 10–40 | 學員 | 跑 skill 定契約 + 裝積木 + `/review` |
| 40–45 | 全體 | 打 `/gate` |

**巡場重點**：攔下想裝三塊以上的人。

**時間不夠時**：這是**唯一可以壓縮或整站移到課後**的站。
壓縮版：只裝一塊，15 分鐘。

---

## S7 守門與交付（16:20–16:45，25 分）

| 分 | 誰 | 做什麼 |
|---|---|---|
| 0–5 | 講師 | `/ship` 的順序邏輯、git 歷史裡的 key、不可回滾那一格 |
| 5–20 | 學員 | 跑 `/ship`，紅燈就停下來修 |
| 20–25 | 全體 | 打 `/gate` + `/ship` |

**講師要明講的一句話**：
> 沒部署成功不算失敗。有資安報告和維運卡就算過關。

部署卡在帳號 / 網路的人會很多。**不要為了上線而犧牲前面的紀律。**

---

## 收尾（16:45–17:00，15 分）

| 分 | 做什麼 |
|---|---|
| 0–5 | 發 [30 天行動卡](../cards/30-day-card.md) |
| 5–12 | 三個人分享今天的分數曲線（**分享曲線，不是成品**） |
| 12–15 | 收回饋：**卡在第幾站第幾步** |

**最後一句**：
> 你今天帶走的不是一個小工具，是一套你自己改過的 `.claude/`。
> 下週用它做第二個東西，才算真的學會。
