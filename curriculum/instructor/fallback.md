# 應急預案

## 結論卡

| | |
|---|---|
| **原則** | 每一站都要有「沒有網路 / 沒有帳號也能跑」的版本 |
| **最可能發生的** | 場地網路撐不住 30 台同時裝套件 |
| **保底方案** | 全班改用 `labs/reference-project/` 跟跑 |
| **不能放棄的** | S2 的考卷、S5 的寫資產 |
| **下一步** | 課前把「離線包」準備好（見第五節） |

## 一、網路掛掉

### 症狀：全班都連不上

| 站 | 替代做法 |
|---|---|
| **S0** | 用離線包（見第五節）。`npx` 需要網路，事先 `npm pack` 好 |
| **S1** | **完全不受影響**——`/kickoff` 是對話，但需要 API…見下方 |
| **S2** | 同上 |
| **S3** | 改用本機 `claude` 產 v0，不用線上平台 |
| **S4** | 需要 API。無網路 → 改成「紙上推演」，見下方 |
| **S5** | **完全不受影響**——改 hook、寫 command 都是本機檔案編輯 |
| **S6** | 複製 `labs/blocks/` 是本機操作，不受影響 |
| **S7** | 資安掃描（本機 grep + git）不受影響；部署跳過 |

### 完全沒有 API 可用時的「紙上推演版」

**S1、S2、S5 照常跑**（S5 甚至不需要 API 也能完成閘門）。
S4 改成：

```
① 發下 labs/reference-project/S4/expected/loop-log.md
② 學員讀老師的分數曲線
③ 討論：第 2 輪為什麼跳最多？如果是你，第 4 輪會改什麼？
④ 每人寫下「我的三條限制」（範圍 / 評分 / 預算）
```

**這仍然達成 S4 的教學目標**——理解四拍，只是沒有親手跑。

---

## 二、學員沒有帳號 / 額度用完

| 情況 | 做法 |
|---|---|
| 課前就沒訂閱 | 預習信已提醒，助教一對一走 [`免費路線`](../../docs/setup/02-free-routes.md) |
| 課中額度用完 | 兩人一組共用一台，**輪流打字**（不是一人看一人做） |
| 免費路線也不通 | 跟跑參照專案 + 完成 S5（S5 不需要 API 額度） |

**兩人一組的規則要講清楚**：
> 兩個人輪流，一站換一次手。看的人負責唸閘門條目，打字的人負責做。

## 三、線上平台掛掉（S3）

改用本機：

```
> 依 docs/PRD.md 產一個單檔的最小可執行版本，放在 prototype/
> 要求：能跑起來最重要、不要加規格外的功能、key 用環境變數
```

慢一點但一樣達成目的。**S3 的教學目標是「先想清楚再丟給工具」，
不是「一定要用某個平台」。**

---

## 四、時間嚴重落後

決策順序（由上往下砍）：

| 順序 | 砍什麼 | 損失 |
|---|---|---|
| 1 | S6 壓成 15 分（只裝一塊） | 少一次接點的練習 |
| 2 | S6 整站移到課後 | 全端部分變成自學 |
| 3 | S3 壓成 20 分 | 少一次體感獎勵 |
| 4 | S7 的部署跳過，只做資安 + 維運卡 | 沒有公開網址 |
| 5 | S4 的目標降到「1 個測試綠燈 + 1 輪迴圈」 | 深度變淺 |

**永遠不要砍**：
- **S2 的考卷** —— 砍了 S4 失去意義
- **S5 的寫資產** —— 砍了這堂課退化成「教你用工具」

## 五、離線包（課前準備）

網路不穩的場地，課前準備：

```bash
# 1. 把 repo 打包（含 labs/reference-project/ 的完整成品）
git bundle create workshop.bundle --all

# 2. 預先下載 MCP 套件（避免 30 台同時 npx）
npm pack @upstash/context7-mcp
npm pack @playwright/mcp

# 3. 存到 USB 或架個區網 HTTP server
python3 -m http.server 8000
```

現場：
```bash
# 學員從區網取得
git clone http://<講師IP>:8000/workshop.bundle my-workshop
```

## 六、講師自己的環境掛掉

**最糟的情況：你的示範跑不起來。**

準備：
- [ ] 每站的產出物截圖，存在本機（不是雲端）
- [ ] `labs/reference-project/` 的完整內容可以直接投影
- [ ] 助教的機器也裝好，可以接手示範

**說法**（不要慌，這反而是教材）：
> 我的環境現在掛了。這剛好是今天要講的——
> **維運卡的第 5 格「壞了先看哪裡」就是為了這種時刻。**
> 我們先看參照專案，我同時修。

```

```

**這是改進教材最直接的資料。**
