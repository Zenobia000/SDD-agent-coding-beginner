## 重製

### 每站一張，共八張

每張只放三個東西（對應各站的「課堂 15 分鐘版」）：

```
S<n> <站名>

老師講的三個要點
  1.
  2.
  3.

學生要做的一件事
  <一段可直接貼的 prompt>

閘門（5 條）
```

**不要把「回家展開版」的內容放進簡報。** 那是課後讀的。

### 用 pptx_builder 產生

```bash
cd pptx_builder
uv run main.py          # 或 python main.py
```

素材：[`assets/agents-pyramid.png`](./assets/agents-pyramid.png)
