# 開場投影片視覺規範（莫蘭迪・編輯設計向）

## 設計意圖

不是企業簡報模板，是**編輯設計／展板感**：字可以當圖、留白要敢留、色彩要啞光舒服。

## 色票（莫蘭迪）

| 角色 | HEX 參考 | 感覺 |
|---|---|---|
| 紙感底 | `#EDE9E4` | 暖灰米，不刺眼 |
| 卡片／區塊 | `#F7F4F0` | 更淺一層 |
| 主字 | `#3A3735` | 炭褐，不要純黑 |
| 輔字 | `#7A7470` | 煙灰 |
| 主強調 | `#A67C7C` | 霧玫瑰（取代刺眼紅） |
| 次強調 | `#8A9A8B` | 鼠尾草綠 |
| 點綴 | `#7D8B99` | 灰藍霧 |

禁止：高飽和紅、霓虹、紫漸層、品牌 logo、臺積電字樣。

## 字型節奏（圖像裡的「跳」）

- 標題：超大、可歪一點、可當背景水印字
- 關鍵詞：霧玫瑰或鼠尾草色，字重對比拉開
- 說明：小、鬆、安靜
- 數字／步驟：當成裝飾符號，不是 Excel 編號

## 元素

軟邊色塊、紙片層疊、細線、圓點軌跡、溫和圖示；避免硬邊儀表板與整頁表格。
