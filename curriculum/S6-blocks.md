## 課堂 15 分鐘版

**老師講**（5 分）：

1. 全端不是學會五種技術，是**看得出自己缺哪一塊**
2. 每塊積木都是「最小可用實作 + 它的契約」，不是完整框架
3. **只挑兩塊**。貪多會做不完，而且積木的價值在**選擇**

**學生做**（35 分）：打 `/next` 看建議 → 挑兩塊 → 裝。

老師巡場的重點：**攔下想裝三塊以上的人。** 45 分鐘裝不完三塊。

## 動手

1. 看自己缺什麼
   ```
   > /next
   ```
   它會實際看你的檔案，告訴你有什麼、缺什麼、建議下一塊。

2. 挑**兩塊**（不要更多）

   | 積木 | 給你什麼 | 對應 skill |
   |---|---|---|
   | `db` | SQLite schema + migration + 連線封裝 | `/spec` |
   | `api` | 有驗證、有錯誤處理的 endpoint | `/spec` |
   | `frontend` | 六種狀態都處理好的資料元件 | `/spec` |
   | `etl` | 抽取 → 轉換 → 驗證 → 載入，含冪等 | `/spec` |
   | `auth` | 密碼雜湊 + session + 權限檢查 | `/ship` |

3. 先跑對應的 skill 定契約（**不要直接複製 code**）
   ```
   > /spec     # 如果你選了 db 或 etl
   > /spec       # 如果你選了 frontend
   ```

4. 複製積木並改成你的
   ```bash
   cp -r labs/blocks/<積木名>/* ./
   ```

5. 跑測試與考卷，確認**沒有退步**
   ```
   > /review
   ```
   ```
   S4 通過率：___ / 10
   現在：     ___ / 10   ← 不可以更低
   ```

## 回家展開版

### 為什麼是「積木」而不是「框架」

| | 框架 | 積木 |
|---|---|---|
| 你要學 | 整套的規矩 | 一個檔案 |
| 換掉的成本 | 高（重寫） | 低（換那一塊） |
| 適合 | 長期大型專案 | 學習與快速驗證 |

**積木的價值在於「可以只拿一塊」。**
你不需要為了存資料而學整套 ORM，你需要的是一個能跑的 schema + 一個驗證函式。

### 五塊積木各自在解什麼

**`db`** —— 存資料
最容易錯的五件事都幫你預先處理了：
```
✅ 有 created_at（UTC）
✅ 金額用整數存最小單位，不用浮點數
✅ 重要資料軟刪除（deleted_at）
✅ 該唯一的欄位有 UNIQUE 約束
✅ 想清楚哪些真的可空
```

**`api`** —— 對外的門
```
✅ 輸入驗證在邊界（schema），不是散在各處 if
✅ 錯誤回應有固定結構，不吐 stack trace 給使用者
✅ 每個 endpoint 都檢查權限，不只在 UI 藏按鈕
```

**`frontend`** —— 給人看的
六種狀態全部處理：Loading / Empty / Error / Success / Partial / Forbidden。
**設計稿只畫 Success 那一格，其餘五格是你的責任。**

**`etl`** —— 搬資料
```
Extract → Transform → Validate ★ → Load
                          ↑
              最常被省略、也最重要的一段
```
沒有 Validate 的管線是「自動產生髒資料機」。
Load 一定要**冪等**——重跑會炸的管線你不敢重跑，出事就沒救。

**`auth`** —— 誰能做什麼
```
✅ 密碼用 bcrypt / argon2，不是 MD5
✅ session 有過期時間
✅ 每個資源存取都檢查歸屬（防 IDOR ——「換個 id 就看到別人資料」）
```

### 全端的資料流長什麼樣

```
外部來源 ──etl──> db ──api──> frontend
                    ↑           ↓
                   auth ←──────┘
```

**每個箭頭都是一個契約。** 契約沒定義清楚的地方，就是之後會壞的地方。

裝積木時先問：**這塊的上游是誰、下游是誰、契約是什麼？**

### 為什麼只能挑兩塊

除了時間，還有一個更重要的理由：

```
裝 1 塊 → 學會「怎麼裝」
裝 2 塊 → 學會「怎麼接」  ← 這才是全端的核心
裝 5 塊 → 學會「怎麼複製貼上」
```

**接點才是難的地方**，不是任何單一塊。

### 回家怎麼裝完剩下三塊

一次一塊，每塊都走同樣的流程：
```
① /next 看建議
② 跑對應的 skill 定契約
③ 複製積木、改成你的
④ /review + 跑考卷確認不退步
⑤ commit
```

**不要一次裝三塊。** 出問題時你分不清是哪塊的錯。
