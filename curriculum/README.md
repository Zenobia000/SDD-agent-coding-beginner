# 講師手冊：想清楚再生成

> 給講師。學生不需要讀這一份。

---

## 最重要的一件事

**這門課的價值，八成在第 1 站到第 3 站。第 4 到 7 站是驗收，不是重點。**

會這樣講是因為**你和學生都會想快轉前三站**。

前三站看起來很虛 —— 沒有產出物、沒有畫面、就是一直跟 AI 聊天。第 4 站開始才有「文件」可以交。所以現場的壓力永遠是「趕快進到寫 PRD」。

**扛住那個壓力。**

一個前三站走紮實的學生，第 4–6 站的三份文件 AI 四十分鐘就幫他寫完，而且是對的。一個跳過前三站的學生，會拿到一份漂亮的、跟他無關的文件，然後在第 7 站發現生出來的東西不是他要的 —— 但那時候他已經不知道問題出在哪了。

**如果只剩三小時，砍第 6 站，砍第 7 站的一半，不要砍第 1–3 站。**

---

## 不要給的三種答案

| 學生問 | 不要回 | 要回 |
|---|---|---|
| 「我的痛點寫這樣可以嗎？」 | 「可以」／幫他改 | 「【代價】那格的數字是多少？」 |
| 「這個功能要不要做？」 | 「要」／「不要」 | 「不做的話，你的主流程斷在第幾步？」 |
| 「這樣算做完了嗎？」 | 「算」 | 「你 SRS 那條的 Then 寫什麼？跑起來符合嗎？」 |

第三題是最常出現的。**永遠把「算不算做完」丟回給學生自己寫的驗收條件。**

這門課從頭到尾就在教一件事：**「做好了」不是感覺問題。** 你一旦幫他判斷了，這件事就沒教成。

## 兩種排法

### 排法 A：一天（6 小時，含午休）

| 時段 | 內容 |
|---|---|
| 0:00–0:30 | 開場 + 第 0 站 |
| 0:30–1:40 | **第 1 站：填表 + 逼問挖痛點** |
| 1:40–2:10 | 第 2 站：種子簡報 |
| 2:10–2:30 | 收：三個人念自己的【代價】那段 |
| — | 午休 |
| 3:00–4:20 | **第 3 站：meta-prompt 三輪** ← 全課高峰 |
| 4:20–5:10 | 第 4–5 站：PRD + SRS |
| 5:10–5:50 | 第 7 站：餵進平台 + 驗收 |
| 5:50–6:00 | 收尾五題 |

第 6 站（SAD）在這個排法裡是回家作業。

### 排法 B：兩段各 3 小時（推薦）

| 段 | 內容 | 形式 |
|---|---|---|
| **第一段** | 第 0–3 站 | 講師帶 |
| 自主 | 第 4–6 站 | 學生自己做，一週 |
| **第二段** | 互相 review + 第 7 站 | 講師帶，重點在 review |

**推薦 B。** 理由：第 4–6 站的文件需要學生自己安靜地寫，在教室裡寫會變成抄範例。而第二段的互相 review 是排法 A 塞不進去的，那一段的教學效果比講師講三十分鐘還好。

## 第一段（3 小時）逐段

| 時間 | 內容 | 巡場重點 |
|---|---|---|
| 0:00–0:15 | 開場：問「你上次跟 AI 要一個東西，改到第幾次放棄？」 | 讓學生自己說出這門課要解決的問題 |
| 0:15–0:30 | 第 0 站 | 看「什麼會讓我放棄」那格有沒有人空著 |
| 0:30–1:40 | **第 1 站 填表 + 逼問** | 見下方 |
| 1:40–2:10 | 第 2 站種子簡報 | 看「目標受眾」有沒有人寫「所有人」 |
| 2:10–2:30 | 收：三個人念【代價】 | 挑一個沒數字的公開改 |
| 2:30–2:50 | **第 3 站第三輪（P4）全班一起跑** | 見下方 |
| 2:50–3:00 | 交代自主期 | 明講：不要抄 SubTrim |

### 0:30 那一段怎麼帶（第 1 站）

這一站你要處理的不是技術問題，是**學生會敷衍**。

先看**填表階段**：學生自己填「現況／期望表」的時候，最常見的敷衍是「現況」跟「期望」兩格寫得幾乎一樣。這代表他還沒想清楚解決了會是什麼樣子。巡場看到這種，別幫他改，就問一句：「這兩格如果拿掉標題，你分得出哪個是哪個嗎？」

新版逼問 prompt 已經要求 AI 不接受形容詞當答案，但學生還是可能在**跟 AI 對話**的階段打「蠻常的」敷衍過去，被 AI 追問幾次就不耐煩、開始亂編。**巡場的時候只看一件事：學生的回答裡有沒有數字。**

看到沒數字的，不要幫他想，就問一句：「上次發生是什麼時候？」他會開始回想具體的那一次 —— 具體的那一次裡面就有數字。

**這一站的成功長什麼樣**：學生在某一題被問住，停下來想了三十秒。那三十秒就是這門課開始起作用的時候。

### 2:30 那一刻怎麼帶（第 3 站 P4）

**這是全課的高峰，不要跳過，不要壓縮。**

讓所有人同時貼 P4（逼出歧義那張卡）。然後**請三個人念出他們拿到的第一條假設**。

不要解釋為什麼這很重要。**讓他們自己看著螢幕上那句「我打算假設你要的是……」發現一件事：這個假設是錯的，而且如果我沒問，它就會這樣做下去。**

那一秒之後，你不用再解釋這門課在幹嘛了。

**帶的時候只做一件事**：每個人念完，問他「這一條如果你沒發現，會導致什麼東西做錯？」讓他自己講出後果。

## 第二段（3 小時）：重點是互相當閘門

| 時間 | 內容 |
|---|---|
| 0:00–0:40 | **兩兩交換 SRS，互相找「寫不出 Then 的需求」** |
| 0:40–1:00 | 收：公開改一條最模糊的 |
| 1:00–1:20 | 兩兩交換 PRD，互相找「非範圍裡少了什麼」 |
| 1:20–2:20 | 第 7 站：分四段餵進平台 |
| 2:20–2:50 | **填驗收表** |
| 2:50–3:00 | 收尾五題 |

### 0:00 那一段怎麼帶

規則講清楚：**你的工作不是幫對方改，是找出他寫的東西裡「兩個人會有不同解釋」的地方。**

具體做法：拿到對方的 SRS，隨機挑三條，照著 Then 自己判斷一次「這樣算不算通過」。判斷不出來的，就是有問題的那條。

這一段比你講三十分鐘「怎麼寫可驗證的需求」有效十倍 —— 因為學生是在**當驗收者的位置上**發現問題的，不是在當作者的位置上被糾正。

### 2:20 那一段怎麼帶（填驗收表）

**這是這門課真正的驗收。**

大部分學生會想全部打勾。你要做的只有一件事：**隨機挑一條他打勾的，請他當場示範給你看。**

第一個被抓到「其實沒做到但打勾了」的人，會讓全班重新認真填一次表。

**驗收表全過的學生，通常是驗得不夠認真，不是做得特別好。** 這句話值得在這一段開始前先講一次。

## 開課前必做

| 項目 | 說明 |
|---|---|
| **自己走一遍全部八站** | 用你自己的題目，不要用 SubTrim。你要親身知道第 1 站被 AI 追問到答不出來是什麼感覺 |
| **確認平台可用** | 你選的 no-code 平台，在教室網路下能不能跑、要不要帳號、免費額度多少。**當天才發現要付費就整堂課垮掉** |
| **準備 2–3 個備用題目** | 給想不出題目的學生。要生活化、要有歧義。例：社團排班、家裡冰箱過期、追劇進度、共乘分帳 |
| **準備一個「爛痛點」示範** | 開場時拿它跟好的痛點對照。用「訂閱好多好煩」對照 SubTrim 那段，效果最好 |
| **確認學生有地方打字** | Google Docs、Notion、記事本都行。**不要假設他們會用 markdown 編輯器** |

**你自己沒走過一遍就不要開課。** 這門課全部的教學動作都是「把問題丟回去」，而你要丟得準，得先知道學生會卡在哪。

## 常見的帶課失誤

| 失誤 | 後果 |
|---|---|
| **快轉第 1–3 站，把時間留給寫文件** | 這門課最常見也最致命的失誤。學生拿到三份漂亮的、跟他無關的文件 |
| 幫學生改痛點描述 | 他學不到「怎麼問自己」，只學到「講師覺得怎樣才對」 |
| 跳過第 3 站的 P4 | 整門課最不可取代的一張卡沒了。剩下的部分別的教材也有 |
| 讓學生抄 SubTrim | 他會交出一份很完美的作業，什麼都沒學到 |
| 幫學生判斷「算不算做完」 | 直接毀掉這門課的核心 |
| 允許驗收表全部打勾 | 學生學到「驗收 = 走個形式」，比不驗還糟 |
| 在第 6 站解釋技術名詞 | 這一站要教的是「看不懂就要問」，你替他問了，他下次還是不會問 |

---

## 判斷這門課有沒有教成

看兩件事：

1. **學生能不能說出「AI 原本要替我做什麼決定，被我攔下來了」** —— 說得出至少一條，這門課就成了
2. **學生的驗收表有沒有未通過的項目** —— 全過的那些人，通常是還沒學會驗收

第 1 條說不出來的學生，多半是第 3 站快轉了。**下次排課時把第 3 站的時間再加二十分鐘。**

## 課後

學生問「接下來學什麼」，照這個回：

| 學生的狀態 | 建議 |
|---|---|
| 覺得前三站最有收穫 | **換一個自己的題目再走一遍。** 第二遍會快很多也準很多 |
| 想把 POC 做成真的能用的東西 | [`claude`](../../tree/claude) 或 [`antigravity`](../../tree/antigravity) |
| 想學完整的軟體開發 | [`progressive-sdd`](../../tree/progressive-sdd) |
| 覺得「我又不寫程式，學這個幹嘛」 | 問他：這學期你有沒有交過一份「別人看完還要再問你三次才懂」的東西？這門課教的就是那個 |
