## 一、節奏器：循環工程四拍

全課只有一個框架。**每一站都是同一組四拍，換不同的對象跑。**

```
① 劃邊界 Constrain  —— 一個範圍 / 一個評分 / 一個預算
② 放它跑   Run       —— AI 產候選，人不插手
③ 打分數   Score     —— 二元判準；程式能判就別問人
④ 收判斷   Decide    —— 看曲線、抽查最好的、決定收工
```

| 站 | 對什麼跑四拍 |
|---|---|
| S1 | 題目 |
| S2 | 規格 |
| S4 | 程式 |
| S5 | 資產 |
| S6 | 積木 |
| S7 | 交付 |

S0（開機）與 S3（先跑通）不跑四拍——一個是暖身，一個是體感獎勵。

**一天跑六次同一組動作，這就是設計目的：肌肉記憶。**

## 三、「全部內容都交」怎麼做到

8 小時不可能**講完**所有東西。所以設計是：

```
課堂  = 跑一輪迴圈（動手為主）
教材包 = 全部內容（回家展開）
```

每一站的文件都切成兩層：

| 層 | 內容 | 誰用 |
|---|---|---|
| **【課堂 15 分鐘版】** | 老師講什麼・學生做什麼・貼哪段 prompt | 課堂 |
| **【回家展開版】** | 完整原理・變體・進階・為什麼這樣設計 | 課後 |

學員帶走的不是「聽過」，是**一套已經寫好、他自己改過一次的 `.claude/`**。
回家照 [`../docs/authoring/`](../docs/authoring/) 就能把其餘五種資產展開。

## 四、「我做對了嗎」

這是本課程和一般工作坊最大的差別。

每站結束打 `/gate`：

```
① AI 讀 labs/reference-project/RUBRIC.md 該站的判準
② 實際去看你的檔案（不是憑對話記憶）
③ 回報：通過 / 缺什麼 / 下一步一個動作
```

**二元判準，不給分數。** 不通過就別往前——卡住的成本比重做低。

老師的完整成品在 [`../labs/reference-project/`](../labs/reference-project/)，每站都有 `expected/`。

## 五、時間不夠時砍哪裡

| 剩餘時間 | 跑到哪 | 學員帶走 |
|---|---|---|
| 2 小時 | S0–S2 | 決策卡 + PRD + 考卷 —— **問對問題本身就是產出** |
| 4 小時 | S0–S4 | 加上一個測試綠燈的 v1 |
| 6 小時 | S0–S5 | 加上自己改過的 `.claude/` |
| 8 小時 | S0–S7 | 全套，含公開網址 |

**S6 是彈性緩衝站**，可壓到 30 分或整站跳過（積木改成回家自己裝）。
**S5 不要砍**——那是本課程唯一教「寫」而不是「用」的一站。
