# 開課

課程主體是 [`../BUILD.md`](../BUILD.md) 那一份文件。這個目錄放的是**教它需要的東西**。

---

## 課怎麼跑

學員自己貼、自己看回應、自己判斷。**你不是在講課，是在巡場。**

| 段 | 時間 | 學員在做 | 你在做 |
|---|---|---|---|
| 開場 | 20 分 | 環境 + 讀 CLAUDE.md | 講一件事：**這裡沒有必經的關卡**，工具是參考書 |
| BUILD 1–2 | 70 分 | 框題目、寫 PRD | 巡場。只盯一件事：判準有沒有被含糊帶過 |
| 休息 | 10 分 | | |
| **BUILD 3** | 45 分 | **畫那條線** | **這段你要講 10 分鐘。** 這是全課唯一需要講的東西 |
| BUILD 4–5 | 55 分 | 定 schema、建考卷 | 巡場。盯考卷有沒有邊界 case |
| 午休 | 50 分 | | |
| BUILD 6–7 | 100 分 | 先做程式那半，再做 AI 那半 | 第 60 分鐘喊一次停，叫還在寫的人跑測試 |
| BUILD 8–9 | 60 分 | 接起來、交付 | 巡場 |
| 收尾 | 20 分 | 三個人分享**那條線畫在哪** | 收回饋：卡在第幾步 |

約 7 小時含休息。**時間不夠時砍第 6–9 步，不要砍第 1–3 步。**

---

## 全課只有一個重點

**第 3 步：把系統切成 AI 判斷的部分和程式算的部分。**

其他八步都是為了讓這一步的判斷落地。學員如果只帶走一件事，就是這件。

判斷他有沒有學會的方法：問他

> 「你的專案裡，有哪一件事你原本想交給 AI，後來決定自己算？」

答不出來 → 他還沒畫那條線。

---

## 巡場只盯三件事

**第 1 步**：「怎麼判斷做對了」有沒有被含糊帶過。聽到「品質好」「順一點」就過去追問：
> 如果兩個版本擺在你面前，你會看什麼、數什麼、比什麼？

**第 3 步**：錢的計算、加總、比大小這類事，有沒有被丟進 AI 那格。

**第 5 步**：考卷有沒有邊界 case。只有主流程的考卷會給人虛假的安全感。

## 改成你自己的題目

**骨架不動，只換 `BUILD.md` 裡的題目。**

換之前先確認新題目有這個特性：**它切得開**——有一部分只有 AI 做得到，
有一部分程式就能算，而且兩者的交界處講得清楚。

切不開的題目（例如「幫我寫文案」）不適合當教材，
因為第 3 步會變成空談。

用自己的題目時，記得把 [`../labs/reference-project/`](../labs/reference-project/)
那四份也換成你的產出——**否則學員會照抄 SmartTrip FX**。
