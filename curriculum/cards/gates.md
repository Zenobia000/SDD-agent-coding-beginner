# 閘門檢核卡　｜　每站結束打 `/gate`

> **二元判準，不給分數。全部打勾才進下一站。**
> 卡住的成本比重做低。

---

## S0 開機
- [ ] `claude --version` 有輸出
- [ ] `my-first-loop/` 存在且有 `.claude/`
- [ ] `/next` 列得出 skill 清單
- [ ] 要求跑 `rm -rf` 時被 hook 擋下
- [ ] `.mcp.json` 存在

## S1 問對問題
- [ ] `decision-card.md` 存在
- [ ] 現況有**三個數字**
- [ ] 成功條件至少 1 條能 yes/no
- [ ] 「不做什麼」至少 2 條
- [ ] 分流結論不是「先別做」

## S2 定契約
- [ ] `docs/PRD.md` 七欄位都非空
- [ ] 沒有 Model Rule（「請仔細」「請確保」）
- [ ] 考卷至少 10 筆
- [ ] 其中至少 3 筆邊界 case
- [ ] **基線通過率已記錄**

## S3 先跑通
- [ ] 有能操作的 v0
- [ ] 實際操作過（不是只看截圖）
- [ ] 用考卷抽測 ≥ 3 筆且有記錄
- [ ] v0 存進 `prototype/`
- [ ] 沒有寫死 API key

## S4 迴圈開工
- [ ] `/review` 五維度全綠
- [ ] 測試 ≥ 3 個，含 1 個邊界
- [ ] 考卷通過率**高於 S2 基線**
- [ ] 有分數曲線（**至少兩個數字**）
- [ ] 已 commit 且 message 有 WHY

## S5 方法變資產
- [ ] hook 有你自己加的規則
- [ ] 用 `echo '{...}' | bash` 實測過
- [ ] 在對話中真的被觸發過
- [ ] `.claude/commands/` 有你寫的新檔
- [ ] 打 `/<你的名字>` 有反應

## S6 積木裝配
- [ ] 裝了**恰好兩塊**
- [ ] 每塊都先跑過對應的 skill
- [ ] `/review` 全綠
- [ ] 考卷**不低於 S4**
- [ ] 新增部分有測試

## S7 守門與交付
- [ ] `/review` 全綠
- [ ] `/ship` 無阻擋項且**掃過 git 歷史**
- [ ] 考卷不低於 S6
- [ ] `docs/OPS.md` 七格都填，含「不可回滾的操作」
- [ ] 寫下學到的一件事 + 下次要改的一件事

---

## 不通過時

```
① 重讀那一站的「閘門」——通常漏了其中一條
② 打 /gate 看它說缺什麼
③ 對照 labs/reference-project/S<n>/expected/
④ 卡超過 10 分鐘 → 舉手
```

**卡關不是你的問題，是教材的問題。**
