# 任務分流卡　｜　S1 用

## 一句話判斷

> **這件事，你寫得出 `check()` 嗎？**

## 四格

```
┌────────────────┬──────────┬─────────────────────┐
│ 能用程式驗證？   │ 做錯的代價 │ 怎麼辦               │
├────────────────┼──────────┼─────────────────────┤
│ 可以 ✓         │ 低       │ 直接交給 AI 全自動     │
│ 可以 ✓         │ 高       │ AI 做，人核准          │
│ 部分可以        │ 任意     │ 人機協作：AI 產、人挑   │
│ 不行 ✗         │ 任意     │ 先別做 ← 拆到可驗證再說 │
└────────────────┴──────────┴─────────────────────┘
```

## 落在「先別做」怎麼辦

**不是放棄，是拆。**

```
「幫我寫出好文案」            寫不出 check() ❌
        ↓ 拆成可觀察的條件
「≤ 30 字」                  ✓
「包含產品名 + 一個動詞」      ✓
「不出現這 10 個禁用詞」       ✓
        ↓
變成：AI 產 20 個 → 程式篩 → 人從剩下的挑
                              ＝ 人機協作
```

## 決策卡必填五格

| 格 | 檢查 |
|---|---|
| 一句話定位 | 給 ___ 用的 ___，解決 ___ |
| 現況 | **三個數字**：誰做、一次多久、多久一次 |
| 做對了長什麼樣 | 至少 1 條能 yes/no 回答 |
| **不做什麼** ★ | 至少 2 條 |
| 三條限制 | 範圍 / 評分 / 預算 |

## 值不值得做

```
一年成本 = 一次花的時間 × 頻率 × 12
```

算不出來 → 這件事可能沒有你以為的那麼煩。

## 為什麼「不做什麼」最重要

做功能變太便宜了 → 需求會無限蔓延 → 什麼都沒做完。

**這一欄是你事先寫給未來自己的約束。**
