## 1. 一句話定義

解決 **___（什麼煩惱）___** 的問題。

---

## 6. 限制與規則

- 介面語言：繁體中文（如專案有 UI）
- 技術棧：依 `/spec` 決策；無特別要求時保持輕量（小工具不必上重型框架）
- 若需要 AI：使用 Google Gemini API（`gemini-2.0-flash` 或當前版本）
- API Key 處理：**走環境變數 / 後端 proxy**，絕不寫死在 code（commit 前跑 `/ship`）
- 錯誤處理：每個失敗路徑（空輸入 / API 錯誤 / timeout）都要有對應測試 + 友善訊息

2. ___（驗收 2，例如：傳給朋友他打開能直接用）___
3. ___（驗收 3，例如：跑 5 次都不會壞）___
