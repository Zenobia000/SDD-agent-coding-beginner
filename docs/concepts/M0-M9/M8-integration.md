# M8｜把七關串成一條線（整合 Capstone）

> **單點可控 ≠ 系統可控。**
> 前面七層各自 demo 都很漂亮，真正的考驗是串成一條資料流、**每個交接點都不漏**。

## 七層各司其職

| 層 | 鎖住什麼 |
|---|---|
| M1 | 認問題 |
| M2 | 鎖意圖 |
| M3 | 鎖結構 |
| M4 | 鎖知識 |
| M5 | 鎖行為 |
| M6 | 鎖品質 |
| M7 | 鎖方向 |

> **難度不在任何一層，在交接點。**

## 主資料流：單向、可中斷、每一站都有「預設安全值」

| 順序 | 站 | 來自哪層 | **失敗時的預設行為** |
|---|---|---|---|
| 1 | Moderation 護欄 | M5 | 擋下 → 回拒 |
| 2 | RAG 檢索 | M4 | 沒撈到 → 回「不知道」 |
| 3 | **Provider 抽象層** ★ | M1·M6 | 失敗 → 換一條路徑 |
| 4 | 結構化輸出 | M3 | 解析失敗 → 給保守輸出 |
| 5 | 低信心 → 升級 | M6·M7 | 判斷不了 → 轉人工 |
| 6 | 記錄供回饋 | M7 | 記錄失敗 → 存本地快照 |

> 兩個關鍵：**任一站失敗，不讓整條崩潰**；而且**絕不靜默吐一個錯答案**。

## Provider 抽象層是整個 capstone 的樞紐

```
generate(question, context, provider)
        ├─→ OpenAI : responses.parse
        ├─→ Claude : tool_use
        └─→ Gemini : response_schema
                ↓
        全部吐出「同一個 Answer」
```

`Answer` 長這樣：
```
Answer {
    answer      : 答案本文
    citations   : 引用來源  ← grounding 的交會點
    confidence  : 信心分數
}
```

> **三個分支吐出同一個型別，才算抽象層真的成立。**
> 做到這件事之後，「換一家模型互審」就只是改一個參數。

## 三道防線，責任互不重疊

```
Moderation 護欄 ── 擋髒輸入（最前面）
    └── RAG grounding ── 決定「答不答」
            └── 結構化輸出 ── 決定「答案的形狀」
```

順序本身就是護欄。`citations` 是三者的交會點。
> 缺一條，就漏一整類的錯。

## 不消滅不確定性，讓它去「觸發動作」

```
confidence ≥ 門檻  →  直接回傳
confidence < 門檻  →  升級：跨模型互審（M6）／轉人工
```

- 門檻要用**評估集回測**決定，不是拍腦袋
- 記得設**互審呼叫上限**控成本

## 風險線畫在哪

- **低風險** → 自動互審就好
- **高風險（金流／法遵）** → **一律轉人工**

> 這條分界線是 M9「漸進式授權」的伏筆。

## 主流程長這樣

```
assistant():
    moderate → retrieve → generate → 分流
       ↓          ↓          ↓         ↓
    每一站都有預設安全值

    if confidence < 0.5:  → 升級
```

## 七層驗收檢核（範例門檻）

| 層 | 驗收項 | 門檻 |
|---|---|---|
| M3 | 三家 provider 格式錯誤 | **零** |
| M4 | 沒撈到時回「不知道」的比率 | **≥ 0.9** |
| M5 | 3 個間接注入攻擊 | **全部不越權** |
| M7 | Factuality（事實性） | **≥ 0.8** |

> **換人照做也成立，才算過。**
