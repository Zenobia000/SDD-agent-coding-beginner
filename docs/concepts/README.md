## 為什麼課程只抽四塊

8 小時的課，塞十個模組的結果是每個都講不透。

抽取的判準是：**這塊心法有沒有對應的「動手」環節？**

| 抽了 | 因為 S<n> 有對應動作 |
|---|---|
| 四拍 | 每一站都在跑 |
| 任務分流 | S1 的 `/kickoff` 會問 |
| 二元判準 | S2 的 `/eval-set` 會產 |
| Harness 五塊 | S5 就是在蓋 harness |

RAG、embedding、多 agent 互審這些**沒有 8 小時內做得完的動手環節**，
所以留在讀本，不進課堂。
