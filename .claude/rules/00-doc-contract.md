# 規則 00：教材寫作規約（Doc Contract）

> 本 repo 所有教材檔案的**唯一格式真相源**。
> 這條規約本身就是它要求的樣子——結論先行、可核對、結尾一個動作。

---

## 結論卡

| | |
|---|---|
| **做什麼** | 規定 `curriculum/`、`docs/`、`labs/` 每份文件的固定骨架與寫作紀律 |
| **為什麼** | 學員是初學者且時間有限；AI 產出的長文是他們最大的認知負擔 |
| **判準** | 每條都能用 yes/no 核對，`/lesson-check` 會逐條掃 |
| **下一步** | 寫任何教材前，先把「結論卡」四格填完 |

---

## 1. 為什麼有這條規約

教材失敗的方式不是「寫得不夠多」，是**寫得太多、讀者找不到結論**。

```
❌ AI 的預設輸出          ✅ 這份規約要的
背景鋪陳 3 段        →   結論卡 4 行
可能的方案 7 種      →   一個建議 + 一個例外
「你可以考慮…」      →   下一步：恰好一個動作
```

一句話：**降低決策成本，不只是降低字數。**

---

## 2. 站別教材（`curriculum/S*.md`）的固定七段

順序不可調換，段名不可改寫。

```markdown
# S<n> <站名>

## 結論卡
## 課堂 15 分鐘版
## 動手
## 閘門
## 我做對了嗎
## 回家展開版
## 下一步
```

| 段 | 內容 | 硬限制 |
|---|---|---|
| **結論卡** | 做什麼 / 為什麼 / 產出 / 下一步 | ≤ 5 行，30 秒可讀完 |
| **課堂 15 分鐘版** | 老師講什麼・學生做什麼・貼哪段 prompt | ≤ 1 螢幕 |
| **動手** | 編號步驟，**每步恰好一個動作** | 每步一行指令或一次貼上 |
| **閘門** | 二元檢核（yes/no） | ≤ 5 條，全打勾才進下一站 |
| **我做對了嗎** | 指向 `labs/reference-project/S<n>/expected/` | 必須有具體檔名 |
| **回家展開版** | 完整原理・變體・進階 | 課堂不講，長度不限 |
| **下一步** | **恰好一個**可執行動作 | 只有一句 |

---

## 3. 八條寫作紀律

### ① 結論先行
第一個非標題段落就是結論。不准用「在開始之前，我們先來了解…」開場。

### ② 一次一個決策
一份文件裡需要讀者做的選擇 ≤ 1 個。有兩個以上就拆檔。
給選擇時：**先寫建議答案**，再給 2–3 個選項，並標明預設值。

### ③ 清單最多 5 項
超過 5 項表示你沒分類。分類完再寫。

### ④ 三級證據標記
凡是「事實宣稱」都要標明來源強度：

| 標記 | 意思 | 什麼時候用 |
|---|---|---|
| **已確認** | 有 code / log / 官方文件直接佐證 | 引用時附路徑或連結 |
| **推測** | 目前證據下最合理的解釋 | 要寫出是依據什麼推的 |
| **未知** | 會改變結論、但還沒查證的那一件事 | 明寫「查證方式」 |

絕不為了簡潔把推測寫成已確認。

### ⑤ 時間估計要給區間與前提
```
❌ 「這步大約 15 分鐘」
✅ 「5–15 分鐘（前提：MCP 已裝好）；沒裝過 MCP 的話 30–40 分鐘」
```

### ⑥ 專有名詞第一次出現必須白話解釋
格式：`**術語**（白話一句）`。例：`**harness**（你幫 AI 配置的整套工作環境）`。
同一份文件內同一術語只解釋一次。

### ⑦ 不重述其他文件
每個事實只有一個真相源（SoT）。要引用就給相對路徑連結，不要複製內容。
違反這條，就會產生本次重構在修的那種「兩條主幹打架」。

### ⑧ 結尾恰好一個下一步
不是「你可以做 A、B 或 C」。是「下一步：跑 `/gate`」。

---

## 4. 不適用的情況（例外）

以下三種放寬，但要在文件開頭註明：

| 例外 | 放寬什麼 |
|---|---|
| `回家展開版` 段內 | 長度不限、可多分支、可列完整選項 |
| `docs/concepts/` 參考讀本 | 不需要七段骨架，但仍需結論卡與證據標記 |
| `labs/reference-project/` 的 `expected/` | 是產出物快照，不是教材，不受本規約約束 |

---

## 5. 怎麼驗證這條規約有生效

```bash
# 掃單一檔案
claude -p "用 lesson-check 檢查 curriculum/S1-frame.md"

# 掃全部
claude -p "用 lesson-check 檢查 curriculum/ 下所有 S*.md"
```

`PostToolUse` hook（`.claude/hooks/check-doc-contract.sh`）會在你寫入 `curriculum/*.md` 後自動提醒缺哪一段。
