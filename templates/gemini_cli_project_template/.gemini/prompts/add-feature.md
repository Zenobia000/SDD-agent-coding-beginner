# Prompt：加新功能

> 想為現有專案加一個小功能時用。把 `___` 填好整段送出。

---

## 模板（複製這段）

```
我想加一個新功能。請依照 @GEMINI.md 的五步流程執行。

【新功能描述】
___（一句話說這個功能做什麼，例如：摘要產生後，加一個「複製到剪貼簿」按鈕）___

【觸發時機】
___（什麼時候會用到，例如：使用者看完摘要想分享給同事時）___

【期望行為】
1. ___（步驟 1，例如：按按鈕後，摘要文字複製到剪貼簿）___
2. ___（步驟 2，例如：按鈕文字暫時變成「已複製 ✓」維持 2 秒）___
3. ___（步驟 3，例如：2 秒後恢復原本文字）___

【限制】
- 不要影響現有功能（測試一次原本流程還能跑）
- 不要新增任何套件
- 不要改動 PRD 沒有提到的其他部分

請先重述你理解的功能，再列出要改哪些地方，等我回 OK 再動手。
動手前請開 checkpoint（這樣壞了我可以 /restore）。
```

---

## 加功能的黃金法則

1. **一次只加一個** — 不要「順便也加 ___」
2. **加完先測** — 確認新功能能用，且原功能沒壞
3. **壞了立刻喊停** — 跟 AI 說「打 `/restore` 回到上一版，重新規劃」
4. **如果 PRD 沒寫到** — 先決定「這要加進 PRD」還是「只是試試看」

---

## CLI 額外好處

Gemini CLI 的 `checkpointing` 預設開著時，每次它動檔案前都會自動 snapshot。
如果加功能加壞了，直接：

```
/restore
```

選一個之前的快照復原。Antigravity 沒這招，這是 CLI 的優勢。
