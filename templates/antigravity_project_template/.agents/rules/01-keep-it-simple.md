# 規則 1：簡單第一原則（KISS）

> 對 Antigravity Agent：違反此規則 = 任務失敗。

---

## 核心信念

**這位使用者沒寫過程式。** 任何超過他理解能力的東西，就算技術上更好，都是壞的。

---

## 強制規則

### ✅ 一定要做

- **單檔優先**：能寫在一個 `index.html` 裡就不要拆檔
- **零依賴優先**：能用原生 JS 就不要裝套件
- **複製即用**：使用者下載 zip 後雙擊就要能跑
- **UI 極簡**：一個輸入框 + 一個按鈕 + 一個結果區，三件以下

### ❌ 絕對不要

- 不要建 `package.json`、`node_modules`、`webpack.config.js`（除非使用者明確要）
- 不要用 TypeScript（除非使用者明確要）
- 不要寫單元測試（這是 v1，能跑優先）
- 不要做「萬一未來要 ___」的設計 — YAGNI
- 不要做使用者沒問的「優化」（loading 動畫、深色模式、響應式 RWD…除非他要）
- 不要重構既有 code（除非有 bug）

---

## 取捨判斷

| 兩種寫法 | 選哪個 |
|---|---|
| A 寫起來 5 行；B 寫起來 50 行更「正規」 | 選 A |
| A 用 `alert()`；B 做漂亮的 modal | 選 A |
| A 全寫在一個檔；B 拆 5 個檔更「乾淨」 | 選 A |
| A 變數叫 `news`；B 用泛型 `T extends Content` | 選 A |

**口訣**：寫到讓使用者打開 code 能看懂在做什麼，就是好 code。
