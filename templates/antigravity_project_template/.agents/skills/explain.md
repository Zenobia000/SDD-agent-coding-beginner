# Explain Project Skill

當使用者要你「白話講一下這個專案」或打 `/explain` 時，先讀以下兩份文件：

- PRD：`docs/PRD.md`
- 站立規則：`AGENTS.md`

用 5 句話跟一個完全沒寫過程式的人解釋：

1. 這個專案要解決什麼問題
2. 使用者會怎麼操作（按鈕？輸入？）
3. 技術上大概用了什麼（單檔 HTML？某個 API？）
4. 目前完成到哪
5. 下一步該做什麼

語氣要像跟朋友聊天，不要用 jargon。
