# Prompt：開新專案的第一句話

> 把整段複製貼到 Antigravity 對話框，按送出。

---

```
請先讀以下兩份文件，再開始工作：

1. AGENTS.md（你的工作守則）
2. docs/PRD.md（我的需求規格）

讀完後，請依照 AGENTS.md 的「Vibe Coding 五步流程」執行：

1. 先用 5 行內重述你理解的需求，讓我確認沒誤會
2. 列出你打算建立 / 修改的檔案清單（不要寫 code，只列檔案）
3. 等我回「OK 開始」之後，才動手寫 index.html
4. 寫完後告訴我：怎麼打開、怎麼測試、預期看到什麼

請開始第 1 步。
```

---

## 為什麼這樣寫

| 這句話 | 在做什麼 |
|---|---|
| 「請先讀 AGENTS.md / PRD.md」 | 強迫 AI 對齊規則和需求，避免它跳過直接寫 |
| 「先重述需求」 | 揪出誤會（很多時候 AI 理解的跟你想的不一樣） |
| 「先列檔案，不要寫 code」 | 讓你看得懂它要做什麼，不會一次吐 500 行嚇死你 |
| 「等我回 OK 才動手」 | 你掌握節奏，不是被 AI 牽著跑 |

---

## 接下來要說的話

當 AI 完成第 1 步（重述需求），你可能要回：

- ✅ 沒誤會 → 「正確，繼續第 2 步」
- ⚠️ 有誤會 → 「不是這樣。我要的是 ___，請重述一次」

當 AI 完成第 2 步（列檔案），你回：

- ✅ 看起來合理 → 「OK 開始」
- ⚠️ 太多檔案 → 「先做最簡單的版本，只用一個 index.html」
