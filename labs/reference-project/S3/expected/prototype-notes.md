## 這告訴我什麼

**v0 的價值不是它能跑，是它爆的地方就是下午要解的問題。**

三個發現：

1. **它只實作了 happy path**
   PRD 的 Constraints 寫了「任一來源失敗時其餘照常」，但它沒做。
   → **原因**：一站式平台傾向產出「能 demo 的東西」，不是「能上線的東西」

2. **它寫死了 API 呼叫，沒有注入點**
   我沒辦法在不動網路的情況下測它 → 測試會慢且不穩
   → S4 要先把外部呼叫抽成可替換的邊界

3. **捨去規則它做成四捨五入**
   PRD 明寫「無條件捨去」，它用了 `round()`
   → **這種細節錯誤最危險**：看起來對，但每次都差一點
