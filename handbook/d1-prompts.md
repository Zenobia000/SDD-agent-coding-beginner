# D1 通用操作提示詞

## d1-read｜唯讀認識練習資料夾
```text
只讀目前練習資料夾，告訴我已有什麼、如何在瀏覽器開啟。這是D1獨立練習，不是LeaveBot；不修改檔案，不讀其他專案資料。
```

## d1-1｜初始指令與一次固定追加
```text
請直接完成我接下來貼的題目，使用目前獨立資料夾。遵守題目的共同規則、素材、時限與驗收要求；不要只寫計畫。由我計時，製作截止前兩分鐘會收到一次固定追加，截止後停止修改。不得使用 MCP、外部圖片或影片生成服務。未驗證事項如實回報。
```

## d1-2｜補上下文再比較
```text
這是另開一輪的教學對照，不是上午固定規格的評測。在新資料夾、新對話做同一題，沿用相同時間、工具與模型，固定追加的內容與時點不變。本次只改一項上下文如下：＜填入＞。不要讀第一版原始碼，不使用 MCP、外部圖片或影片生成服務；前三題不得加入外部圖片，播放器保留同一份指定素材。完成後依相同條件比較，註明這一輪變動了哪些輸入，不併入原評測排名。
```

## d1-3｜修一個問題
```text
我看到：＜實際畫面或重現步驟＞。我期待：＜可觀察的結果＞。
評測已截止，原版本已保存。現在只在另存的練習副本修復，不更改原評分。
先找出差異與原因，再只修這一件事。實際開啟並驗證；沒有瀏覽器工具就列出我要操作的步驟，不假裝已通過。
```

## d1-4｜回顧 AI 自行做的假設
```text
列出這次作品裡我沒有明確指定、由你自行決定的事項。每項附畫面或檔案依據，讓我選擇保留、修改或不做。這一步只討論，不修改檔案；等我確認再整理PRD。
```

## d1-5｜今天收斂到 PRD
```text
根據剛才已確認的決策，將這個作品整理成目前練習資料夾內的 prd.md。
包含目標使用者、問題、核心流程、這次做與不做的範圍、至少三條 Given/When/Then 驗收條件（至少一條失敗情境）與待決事項。
這是D1簡版，不使用LeaveBot專案模板或公司規則。不補未確認需求，不寫程式，不畫流程圖。
```
