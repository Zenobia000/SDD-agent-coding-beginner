三題體驗：先選一題

每題 6 分鐘製作＋2 分鐘操作。一次提示，允許 Agent 自行修正；人補提示另記次數。以下為課堂設計題，未實測保證完成時間。

先了解：我們在觀察哪些能力？
面向看什麼
需求遵循要求是否完整落地，有無自行改規格
視覺實現A 看還原精度；B 看片面、字體與配色是否一致，分開評
互動完整操作、回饋、結果、重設是否連貫
邏輯正確條件、不重複選取、狀態重設是否正確
空間與時間位置、動態與事件順序是否一致
自主完成有無真正啟動、操作、找錯與修復

有圖片輸入並對照輸出，才能進一步觀察多模態理解。漂亮畫面不直接證明內部推理；一次結果也不代表模型整體排名。

A｜網站首屏臨摹

主要觀察：讀圖與還原精度。

開啟目標成品：Linear 首頁 →
① 準備上下文

已附固定尺寸 1440 × 900 的原站截圖：下載 reference.png（擷取日期：2026-10-25；來源：Linear 官網）。下載後放到練習資料夾，再與提示詞一起交給 Agent。這張圖就是還原目標，網址只供對照；測讀圖時不要讓 Agent 讀原站程式。截圖沒有獨立素材包，缺圖可本地近似並註明差異。

② 展開完整提示詞
請在目前的獨立練習資料夾建立可於瀏覽器執行的作品，不要只提供計畫或程式碼片段。直接動手，不要提問；未指定的細節自行決定。使用既有套件，不建後端、不登入、不呼叫付費 API 或圖片影片生成服務。不要下載新素材；可用 CSS、SVG 或 Canvas 自製圖形。介面使用繁體中文（臨摹題保留參考圖原文）。
製作預算為 6 分鐘，由講師計時；時間到就保留當前版本，另用 2 分鐘操作。優先完成核心流程，再改善外觀。允許自行執行與修正；有瀏覽器工具就實際開啟、操作與檢查。沒有工具不得假裝驗證。完成時回報啟動方式、實際驗證項目、未完成或未驗證項目。

附件 reference.png 是必須重現的完成畫面，不是風格靈感。請還原這一屏的導覽、標題、按鈕、產品展示區、文字、比例、間距與配色，不得自行改版。不做截圖範圍外的區塊。若有 assets 資料夾，只使用其中素材；缺圖以本地 SVG 近似，交付時列出差異。
以 1440 × 900 驗收；縮至 1024 × 768 時核心內容不得重疊。主按鈕點擊後顯示可關閉的體驗說明，導覽項目有 hover 與鍵盤焦點回饋；這兩項是課堂新增的互動，不是對原站行為的推測。
③ 操作驗收：五件事
  1. 同尺寸並排比較主要區塊位置
  2. 標題與內文完整
  3. 主按鈕及關閉有效
  4. 鍵盤可聚焦導覽與按鈕
  5. 縮小視窗不重疊

記錄通過幾項／5、首次可用時間、補提示次數、手動改碼次數，以及修復前後結果。品味另由同學盲選，不與功能分數混算。

  2. 三張牌不重複且對應三個位置
  3. 翻面後內容可讀且各不相同
  4. 快速連點不多抽
  5. 重新開始後狀態清空

講師備課：怎麼準備 Reference 與公平比較？

上課前親自開啟原站，固定相同尺寸與截取範圍，將 reference.png 或 start.png、middle.png、end.png 與 scroll.mp4 放進各組題目資料夾。確認 Agent 能讀取提供的格式；不能讀影片時，改提供相同關鍵影格與動作文字。先試跑，確認套件與啟動方式。原站網址是可對照的目標成品，不能以元件庫代替。
