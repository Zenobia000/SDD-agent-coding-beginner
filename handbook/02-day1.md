# D1｜Vibe Coding：從驚喜到PRD

在獨立D1資料夾，與LeaveBot分開。第一天只練工具、上下文、操作與需求，不寫整套工程文件。

## 認識 Coding Agent：交代任務，看到作品（09:00–09:45）

用自然語言讓 Agent 建立作品，先體驗它能做什麼。

現在做這件事 觀察講師下任務、產出檔案、啟動與操作的過程。

完成就打勾 說出 Agent 與純聊天工具的一個差別。

## Claude Code 基礎操作（09:45–10:30）

會啟動、交代任務、查看改動與停止操作。

現在做這件事 在自己的練習資料夾啟動工具，先做唯讀探索，再建立一個小頁面。

完成就打勾 能啟動工具，指出產出的檔案，並在瀏覽器看到畫面。

## 三種吸睛 Demo，觀察不同能力（10:45–12:30）

看懂三題各在測什麼，再挑一題親手試。

現在做這件事 看網站臨摹、塔羅抽牌與捲動動畫的短示範；每題以 6 分鐘製作＋2 分鐘操作為上限。

完成就打勾 能區分還原精度、設計品味與互動邏輯。

## 自己做一次：一個提示詞、一個作品（13:30–14:15）

一次給出要求，觀察它如何補足未指定的細節。

現在做這件事 選一題，將共同規則與題目合併成一次輸入；保留第一版，不補提示。

完成就打勾 留下可執行的第一版或實際失敗紀錄。

## 補上上下文，比較第二次結果（14:15–15:00）

提示詞之外，參考圖、素材與限制也會改變結果。

現在做這件事 在新資料夾重跑同題，加入固定截圖或更清楚的規格，再與第一版並排。

完成就打勾 指出一項因上下文改變而改善或退步的地方。

## 操作驗收：好看之外，真的完成了嗎？（15:15–16:30）

成品看起來完成，仍要實際操作才知道。

現在做這件事 依題目的五項條件操作，記錄通過項目，再讓 Agent 修一個最明顯的問題。

完成就打勾 留下通過項數、人工介入次數，以及修復前後結果。

## 把體驗收斂成 PRD 草稿（16:30–17:30）

把剛才試出來的需求寫下來，今天到 PRD 為止。

現在做這件事 列出 AI 自行決定的事，由人確認保留、修改或不做，再整理為 PRD。

完成就打勾 PRD 有使用者、核心流程、範圍、待決事項與至少三條驗收條件。

## 三題：選一題實作

每題6分鐘製作、2分鐘操作。固定題目、素材、工具與時間，記下人工介入；預算不是完成保證。

③ 操作驗收：五件事

同尺寸並排比較主要區塊位置 標題與內文完整 主按鈕及關閉有效 鍵盤可聚焦導覽與按鈕 縮小視窗不重疊 記錄通過幾項／5、首次可用時間、補提示次數、手動改碼次數，以及修復前後結果。品味另由同學盲選，不與功能分數混算。
