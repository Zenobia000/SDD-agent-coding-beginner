# Vibe Coding 一日工作坊

> **8 小時，從沒寫過程式 → 做出第一個可運行的小專案。**
> 全程免費工具（Google AI Studio + Antigravity 桌面版 + Antigravity CLI），公開教案、可自學、可二創。

## 這堂課在解什麼問題

**問題**：你會用 ChatGPT / Gemini 聊天，但每次想把腦中那個「好希望有 XX」變成可用的東西時，就卡住——不知道怎麼寫 prompt、不知道用什麼工具、做出來的東西長得不像你要的。

**這堂課的承諾**：

| 8 小時內 | 你會做到 |
|---|---|
| 09:00 | 進教室。會用瀏覽器，但對「終端機」陌生 |
| 12:30 | 中午能說出「我下午要做的是給 ___ 用的 ___」 |
| 15:30 | 螢幕上有自己的小專案在跑（不是講師的 demo） |
| 17:30 | 朋友問你今天學什麼，能打開電腦秀給他看 |

**這不是程式入門課**。我們不教 for-loop、不教 git rebase、不教 React hooks。我們教**怎麼把 AI 當共同作者**，讓它幫你寫出可運行的東西，而你掌握方向與決策。

## 你會帶走的具體產出

不是 PPT 截圖、不是「啟發」，是 7 樣可以打開、可以重用的東西：

1. **一個可運行的小專案**（本機可跑，選修上線後有公開網址）
2. **專案 PRD**（用 STRIKE 六字訣寫出，存進你的 Notion / HackMD）
3. **STRIKE 速查卡**（六字訣 S/T/R/I/K/E + MVP 組合 T+K+I + 三層策略 L1/L2/L3）
4. **工具選擇決策樹**（下次要做新東西時，知道先開哪個工具）
5. **30 天 Vibe Coding 路線圖**（回家每週做一件事，避免「上完課就忘」）
6. **痛點物理量檢驗單**（下一個專案直接套用）
7. **追問三指令卡**（「為什麼？」「還有別的嗎？」「找漏洞」——防 AI 一本正經地胡說）

## 為什麼是這三個工具

**選擇原則**：開源、免費、循序漸進、學完換工具不歸零。

| 工具 | 介面 | 對初學者的角色 | 你會學到的可遷移技能 |
|---|---|---|---|
| **Google AI Studio** | 瀏覽器 | 零安裝，今天的第一口飯 | Prompt 框架（STRIKE）、可遷移到任何 LLM |
| **Antigravity 桌面版** | IDE（桌面） | Agent-first IDE，今天的主戰場 | Vibe Coding 五步流程、可遷移到 Cursor / Claude Code |
| **Antigravity CLI（`agy`）** | 終端機 | 終端機的 AI agent，今天的收尾與延伸 | 2026 通用 coding agent 詞彙（AGENTS.md / MCP / Skills）、跨工具通用 |

**換工具不歸零**：今天學的 STRIKE 戰法、`AGENTS.md` 慣例、MCP 概念，**在 Claude Code、Cursor、Codex 都通用**。工具會更迭，方法會留下。

## 三種使用這個 Repo 的方式

### 一. 自學路徑（學員視角）

不一定要進實體課程，這個 repo 本身就是一份完整自學教材：

```bash
# 1. clone 下來
git clone https://github.com/<you>/ai-vibe-coding-beginner.git
cd ai-vibe-coding-beginner

# 2. 把模板複製出來當你的專案
cp -r templates/antigravity_project_template my-first-vibe-project
cd my-first-vibe-project

# 3. 一鍵啟動三面板工作站（zellij：RUN / WATCH / CHECK）
./start              # macOS / Linux / WSL
start.bat            # Windows（雙擊即可）

# 4. 看 USAGE.md 選模式（A: 新手五步 / B: SDD 十站）→ 貼 .agents/prompts/start-project.md 給 AI
```

> **不想用工作站？** 直接 `cd` 進去打 `agy` 也可以。`start` 是給「不想每次手動切視窗」的人。

**建議閱讀順序**：

| 你的狀態 | 先讀 |
|---|---|
| 完全沒概念 | [`class_plan/core_curriculum.md`](./class_plan/core_curriculum.md) §0–§3（10 分鐘） |
| 想動手做第一個專案 | [`templates/antigravity_project_template/USAGE.md`](./templates/antigravity_project_template/USAGE.md) |
| 想理解教材為什麼這樣設計 | [`templates/ai_ready_repo_blueprint.md`](./templates/ai_ready_repo_blueprint.md) |
| 想看完整 8 小時流程 | [`class_plan/teaching_plan.md`](./class_plan/teaching_plan.md) |

### 三. 改造路徑（教育工作者視角）

想把這份教案改成「半日精簡版」、「兩日深入版」、或「給特定行業（律師 / 行銷 / 醫療）」的客製版？

**改造建議**：

| 你想做 | 主要動哪 |
|---|---|
| 半日精簡版（4 hr） | 砍 M4 + M5，把 M3 縮成 60 分鐘的單一範例 |
| 兩日深入版 | Day 1 走完現有教案；Day 2 加 GitHub / CI/CD / 部署實戰 |
| 行業客製版（如行銷） | 改 M1 痛點範例 + M2 STRIKE 範例 + M3 範例專案，骨架不動 |
| 公司內訓 | 把 M5 行動卡改成「下週四前產出 X」對齊 OKR |

**模板層也可改造**：[`templates/antigravity_project_template/`](./templates/antigravity_project_template/) 是一套完整的 AI-ready repo 骨架（含 SDD Sprint 工作流 + 10 個 slash command），不只給工作坊用，**任何想用 Antigravity / Claude Code / Codex 跑 Spec-Driven Development 的人**都能直接拿去用。

## 課後延續：30 天行動卡

下課不是結束。**沒在 30 天內做出第二個專案，今天學的東西會忘 80%**。

| 週 | 行動 | 為什麼 |
|---|---|---|
| Week 1 | 把今天的小專案再改一個功能 | 把「課堂手感」變「家裡手感」 |
| Week 2 | 找新痛點，用物理量四問再篩一次 | 練「找對題目」比「做對東西」重要 |
| Week 3 | 第二個專案完整跑一輪 STRIKE → Vibe Coding → CLI | 證明「不是只在課堂才做得到」 |
| Week 4 | 把成品分享給 3 個人，收 3 句具體回饋 | 跳出「為自己做」進入「為使用者做」 |

完整行動卡會在 M5 發放紙本版。

## FAQ

**Q：完全沒寫過程式真的能跟上嗎？**
A：能。本課**不教程式語法**——你會用「自然語言」描述需求，AI 寫 code，你看結果決定下一步。整堂課 64% 是學員動手，講師會逐段帶；卡 > 2 分鐘助教就會過來。

**Q：免費工具真的夠用？會不會有隱藏付費？**
A：完全免費。Google AI Studio 有免費額度（用完才付費，課程內絕對用不完）；Antigravity 桌面版與 CLI 是 Google 免費釋出（2026 Public Preview）；Cloudflare Pages 部署免費。

**Q：上完課我能接案 / 創業嗎？**
A：誠實答：不能。**這堂課是入門**——讓你「能做出第一個東西」，不是「能交付商業案件」。但你會帶走一張 30 天行動卡，跑完後再上進階課程會差很多。

**Q：和市面上其他 AI 課程的差別？**
A：三點：(1) **三工具串接而非並列**，學完不用自己拼；(2) **STRIKE 戰法跨工具通用**，工具會更迭、方法會留下；(3) **64% 動手時間**，不是看講師 demo。

**Q：我是工程師也適合來嗎？**
A：適合，但不是 sweet spot。建議直接讀 [`templates/antigravity_project_template/`](./templates/antigravity_project_template/) 跑 Mode B（SDD Sprint 十站），更符合你的程度。

**Q：可以把這份教材拿去開自己的課嗎？**
A：可以。MIT 授權，可商用、可改編，請保留作者標示。歡迎開 issue 讓我知道你開了什麼課——會列在 README 的「使用案例」段落。

**Q：版本會持續更新嗎？**
A：會。**2026 是 AI coding agent 的劇變年**——Gemini CLI 2026-06-18 停服改為 Antigravity CLI、MCP 成為業界標準、AGENTS.md 跨工具共通格式逐漸成形。本教案會持續追上。
