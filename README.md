# Vibe Coding × SDD｜AI 開發入門實戰工作坊

**把想法做成作品，建立能帶回工作現場的 AI 開發能力。**

AI 讓更多人有機會親手做出網站、互動體驗與工作工具。接下來的挑戰，是把需求說清楚、判斷結果是否正確，並在想法改變時，知道如何繼續修改。

這是 **Sunny Data Science 桑尼資料科學**為開發入門者設計的兩天工作坊。我們從一個看得見的作品開始，帶你練習與 Coding Agent 協作，再用規格驅動開發（Specification-Driven Development，SDD）把需求、實作與驗收接起來。你會在實際操作中，逐步建立自己的開發與判斷方法。

## 為什麼值得學

當你能把需求整理成 AI 看得懂、自己也驗收得了的任務，就更容易把工作中的想法推進成可試用的原型，與同事討論，也為下一次修改留下依據。

這堂課會陪你練習：

- **把想法說清楚**：整理目標、使用情境與完成標準，減少反覆猜測。
- **把 AI 的成果看明白**：透過實際操作與測試，確認功能是否符合期待。
- **把開發過程留下來**：用需求文件、工作票與版本紀錄，讓下一個對話或合作夥伴能接手。
- **把方法用到下一個題目**：從自己的工作挑選小問題，逐步建立可重複使用的協作流程。

## 兩天，走過四個實作環節

| 環節 | 你會練習什麼 |
|---|---|
| 體驗與創作 | 觀察網站臨摹、塔羅抽牌與捲動動畫，選一題用 Coding Agent 做出第一版 |
| 上下文與需求 | 加入參考圖與限制比較結果，整理 AI 自行補上的假設，形成產品需求文件（PRD） |
| 規格與實作 | 以 LeaveBot 請假系統為共同題目，從需求走到流程、最小設計、測試案例與程式 |
| 驗收與交付 | 親手操作成功與失敗情境，練習除錯、需求變更與交接 |

**第一天：從驚喜到 PRD。** 在獨立練習資料夾探索作品，理解提示詞與上下文如何影響結果，最後把已確認的想法收斂成簡版需求。

**第二天：從規格到可驗收的功能。** 與小組完成「填表、驗證、存檔、查看假單」的開發練習，學習用證據判斷完成，並體驗需求改動時如何保持一致。

課程為兩天、共 14 小時的實作安排。每個階段都有明確任務與驗收條件，依課堂進度逐步展開。

## 你能帶走什麼

- 一份自己的作品初版、比較紀錄與簡版 PRD。
- 一次從共同需求走到表單功能、測試與操作驗收的開發經驗。
- 可用於後續練習的任務描述、提示詞與驗收方法。
- 一套整理決策、處理錯誤與交接成果的工作習慣。

你可以用這些經驗準備下一個原型、與工程夥伴討論需求，或重新檢視工作中值得改善的小流程。工具持續變化時，清楚定義問題與驗證結果的能力，仍能幫助你做選擇。

## 適合誰參加

希望把 AI 用進實際工作的初學者，以及想親手驗證產品想法的產品、營運、行政與其他跨領域工作者，都可以從這堂開發入門課開始。已有程式經驗的學員，也能用共同題目練習規格、測試與 Agent 協作。

課前請依 [環境準備講義](handbook/site/setup.html) 確認帳號與工具，讓課堂時間能留給實作。

## 開始使用教材

1. 完整解壓講師提供的學生講義 ZIP，雙擊其中的「開啟講義.html」。
2. 若下載的是 GitHub 專案 ZIP，解壓後開啟 `handbook/site/index.html`。
3. 依講師進度進入目前單元，需要時再展開提示詞與補充內容。

HTML 講義可直接以瀏覽器閱讀。第二天的開發練習使用自己的 LeaveBot 專案；Agent、套件下載及外部連結需要網路與相應帳號。
