# 規格驅動 × AI 開發實戰營

> 2 天、14 小時。D1 寫六份規格，D2 讓 AI 照規格從 0 做出全端加 AI 的 app。
> 桑尼資料科學出品。

## 這個 repo 放什麼

```text
handbook/      學員講義：課前準備、兩天課程、提示詞與問題排解
starter-kit/   企業啟動包：AI-Native 企業策略報告、高層簡報、部門拆解與工具
scripts/       產生 HTML 講義、檢查連結
```

**看講義**：`python3 scripts/build-html.py`（要先 `pip install markdown`），產出 `dist/handbook.html`、`dist/starter-kit.html` 與 `dist/deck.html`，雙擊用瀏覽器打開。要 PDF 就用瀏覽器列印。
