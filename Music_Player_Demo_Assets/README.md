# 音樂播放器課堂素材

學生請從 [第四題操作講義](../handbook/site/day1.html#demo-player) 開始，下載 [正式測試素材 ZIP](../handbook/site/assets/demo-player/player-input.zip)，解壓到自己的空白練習資料夾。

正式 ZIP 已包含同一張固定 Apple Music 參考截圖、根目錄 `tracks.json` 及三張 PNG 封面，不需要另外找圖或登入音樂服務。完整初始指令與固定追加的時間，以操作講義為準。

內層 `Music_Player_Demo_Assets/` 保留原始素材包供查考。其 `PROMPT.txt` 已包含切歌狀態要求，與課堂「初始指令＋一次固定追加」的安排不同，請勿預先放入受測 Agent 的工作資料夾。正式追加由教師在製作截止前兩分鐘送出。
