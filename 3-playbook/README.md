# 兵器庫：帶回公司用的四件工具

> 這些是你結訓後，推動團隊導入時能直接拿去用的東西。

| 檔案 | 是什麼 | 誰用 | 什麼時候用 |
|---|---|---|---|
| [`PROMPT-BOOK.md`](./PROMPT-BOOK.md) | **Prompt 魔法書**：需求收斂、架構繪圖、測試窮舉、Debug 救援四篇 | 所有人 | 每天，要叫 AI 做事之前 |
| [`TROUBLESHOOTING.md`](./TROUBLESHOOTING.md) | **問題排解檢索表**：依症狀找步驟，附決策樹 | 工程師、PM | AI 卡住、繞圈、做錯的時候 |
| [`CHECKLIST.md`](./CHECKLIST.md) | **防呆檢核表**：PM、SA、QA、工程師、主管各一欄 | 所有人 | 印出來貼著，每天看 |
| [`ASSESSMENT.md`](./ASSESSMENT.md) | **導入評估表**：10 題，評估團隊成熟度 | 主管 | 結訓時填一次，導入三個月後再填一次 |

規格模板與專案規則範本在 [`2-templates/`](../2-templates/)。

---

## 回公司的第一週

1. 填 [`ASSESSMENT.md`](./ASSESSMENT.md)，找出最低分的那一題。
2. 挑一個**小**專案，從 [`2-templates/`](../2-templates/) 的需求模板開始。
3. 把 [`CHECKLIST.md`](./CHECKLIST.md) 裡你角色那一欄印出來。
4. 卡住時翻 [`TROUBLESHOOTING.md`](./TROUBLESHOOTING.md)，不要叫 AI 再試一次。
